# 🟢 Riyadh Real Estate Live Transaction Radar

A real-time analytics dashboard built with **Python**, **Streamlit**, and **Plotly** to track, stream, and visualize live real estate deals across Riyadh districts with automated auto-refresh capabilities.

## 🚀 Features

- **Live Real-Time Stream:** Automatically fetches and processes active market transactions with periodic auto-refreshing (every 10s).
- **Dynamic KPI Tracking:** Instant calculations for transaction volumes, total value (SAR), and price per square meter.
- **Interactive Visualizations:** Plotly-powered distribution charts and multi-variable scatter plots.
- **Zero-Cost Deployment:** Fully compatible with Streamlit Community Cloud without external paid APIs.

## 🛠️ Tech Stack

- **Frontend & App Framework:** Streamlit, Streamlit-Autorefresh
- **Data Manipulation:** Pandas, NumPy
- **Visualizations:** Plotly Express
- **Networking:** Requests
